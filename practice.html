●The loop that works

  1. Read a page.
  2. Run its Try it blocks — break one deliberately.
  3. Do the Build this project.
  4. Solve the Deep-ML problems at the foot of the page.
  5. Drill that page’s questions a week later.

Four passes, spaced, producing something each time. Slower than reading four explanations, and that is the point.
